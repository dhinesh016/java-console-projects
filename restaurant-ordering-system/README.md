# Restaurant Ordering System (Java)

A console-based restaurant ordering system developed using Java.  
The application allows users to view menu items, place orders, modify orders, and cancel orders.

## Features

- Display restaurant menu
- Order food items
- Modify ordered items
- Remove items from order
- Cancel complete order
- Calculate total bill

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Console-based interaction

## How to Run

Compile the files

javac Restrunt/*.java

Run the program

java Restrunt.Driver
