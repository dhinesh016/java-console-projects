# Number Guessing Game (Java)

A simple console-based number guessing game developed using Java.

The program generates a random number between 0 and 100, and the player has 3 attempts to guess the correct number.

## Features

- Random number generation
- Limited guessing attempts
- High / Low hints for each guess
- Console-based interaction

## Technologies Used

- Java
- Random class
- Scanner class
- Control statements

## How to Run

Compile the program

javac Game.java

Run the program

java Game
